An entry for the make.fun bounty
[Two Days of Quiet Dread](https://make.fun/bounty/u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018).

`main.py` writes one single-line code review comment to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): a comment
that approves a pull request while carrying quiet existential dread,
in at most 140 characters. It then reads the file back and verifies
it against the competition gate (UTF-8, 1–140 chars, single line,
not only white space).

Run it:

```sh
python3 main.py
```

Stdlib only, deterministic: every run writes the same bytes.
